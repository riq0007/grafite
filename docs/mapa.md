# Mapa do Grafite

Onde está cada decisão, cada spec e cada change, e o glossário. O mapa aponta; o conteúdo fica no arquivo citado. O `scripts/mapa.test.ts` reprova o mapa que cita o que não existe.

## 1. Como usar

1. Leia o mapa antes de abrir um documento: ele diz em que seção, spec ou change está o que a tarefa pede.
2. Abra só essas partes; o resto do arquivo fica fechado até a tarefa pedir.
3. O mapa aponta e não decide: o que ele disser diferente do arquivo é erro do mapa, e vale o arquivo.

## 4. Contrato de módulo por seção

Quando abrir cada seção de `docs/casca/modulos.md`.

| Seção | Abra quando |
|---|---|
| Passo a passo | vai criar um módulo ou pôr uma tela nova nele |
| Campos da entrada | vai declarar ou mudar a entrada do módulo no registro, ou pôr no menu do dock itens que vêm dos dados, como as visões fixadas |
| Busca | vai pôr uma tela, uma ação, um ajuste, os registros do módulo ou as ações da tela aberta na busca |
| Ocorrências na tela inicial | o módulo tem ocorrências para "O que resolver agora" |
| Notificações | o módulo avisa o usuário, na tela, por e-mail ou no celular |
| Indicadores | o módulo mostra um indicador, com a meta, a situação e a decisão |
| Datas e horas | a tela mostra uma data ou uma hora |
| Prévia na tabela | a tabela abre a prévia de um registro pela barra de espaço |
| Tabela configurável e visões | a tabela tem colunas escolhidas, filtros pelas colunas e visões |
| Relações nas fichas | o módulo mostra algo na ficha de um registro de outro módulo, ou a ficha mostra um dado de outro módulo a quem não vê esse módulo |
| Referência com cartão | a tela cita um registro, com o link e o cartão do resumo, ou abre a tabela a partir de uma origem |
| Escolhas | a tela pede uma escolha: que controle usar, as sugestões do contexto, o local em árvore e o efeito antes de confirmar |
| Cursor | um elemento precisa do abraço do cursor ou do cursor do sistema |
| Permissões | o módulo declara permissões, mostra só o que a conta pode ou diz a quem pedir acesso |
| Módulo opcional | a organização pode desligar o módulo, ou o módulo do dock faz parte de outro e segue o interruptor dele (`parteDe`) |
| Sessão e API | a tela lê quem está na sessão, chama a API ou lê dados com o TanStack Query |
| Confirmação pelo código do app | a tela pede o código do app de novo antes de uma ação sensível, como revelar um segredo |
| Eventos do servidor | a tela se atualiza quando um registro muda no servidor |
| Valores coletados | a tela mostra um valor que o coletor lê, com a situação e a idade da leitura, os vários itens de um ativo, como os suprimentos de uma impressora, ou a coluna de situação de outra capacidade, como o Control iD |
| Preferências | a tela lê ou grava uma preferência da interface |
| Foto da pessoa | a tela mostra a foto de uma pessoa |
| Etapas da chegada | outra parte do app acrescenta uma etapa ao carregamento |
| Exemplos | precisa de um módulo inteiro como modelo |
| Conferência | quer saber que teste reprova a entrada errada |
| Fora do contrato | precisa de algo que o contrato ainda não cobre |

## 7. Glossário

| Termo | O que é | Onde |
|---|---|---|
| Organização | A empresa cliente, raiz de todo dado de negócio, achada pelo endereço de acesso | `isolamento-organizacoes`; spec mestre, seção 4.4 |
| Local e árvore de locais | Onde as coisas ficam, numa árvore livre de até 8 níveis, cada local com um tipo | `locais`; spec mestre, seção 5.2 |
| Pessoa | Todo colaborador, com conta ou sem; o responsável por um ativo é uma pessoa | `administracao-de-pessoas`, `contas-de-acesso` |
| Fornecedor | Quem vende, aluga ou dá assistência aos ativos, num cadastro da organização com o nome e o CNPJ únicos, que o ativo, os consumíveis e o estoque apontam | `fornecedores`; spec mestre, seção 5.1 |
| Consumível e compatível | O que se troca nos equipamentos, como o toner e o cilindro, pelo código do fabricante, único na organização; o compatível de um modelo é o consumível que serve nele | `consumiveis`, `modulo-operacao`; spec mestre, seção 5.4 |
| Estoque, movimentação e mínimo | O saldo de cada consumível em cada local, que só muda por uma movimentação lançada no livro-razão (a entrada, a saída para um ativo, a transferência e o ajuste); abaixo do mínimo do local, o consumível vira uma ocorrência no Início | `estoque`, `modulo-operacao`; spec mestre, seção 5.2 |
